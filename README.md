# AI Creative Studio

> Часть портфолио: [сайт-портфолио](https://auryxn.github.io/site-admin/) — репозиторий сайта [site-admin](https://github.com/auryxn/site-admin).

> Веб-приложение для организации производства фильмов и видео, создаваемых с помощью AI.

## Что это

AI Creative Studio — это «рабочее место» продюсера/режиссёра, который делает
фильмы с помощью нейросетей. Вместо разбросанных заметок и таблиц Studio держит
всю производственную цепочку в одном интерфейсе: от идеи фильма и сценария до
сцен, персонажей, промптов, сгенерированных ассетов и экспорта.

Инструмент рассчитан на небольшую команду или одного автора (AI-режиссёра),
которому нужно понимать, что уже готово, а что в работе. Логика такая: фильм
разбивается на **сцены**, у каждой сцены есть статус (`draft → ready →
generating → review → approved → completed`), и по этим статусам считается
прогресс всего проекта.

Это MVP первой фазы: интерфейс, структура данных и сценарии использования
готовы, а сами генерации (картинки, видео, голос, музыка) пока проходят через
провайдеры-заглушки — реальный рендер подключается позже, без переписывания UI.

## Возможности

- **Дашборд** — список фильмов, прогресс производства, метрики (активные сцены,
  утверждённые кадры).
- **Проекты** — создание и просмотр проектов фильмов.
- **Сценарий (Script)** — сцены правятся в выезжающей панели (drawer).
- **Раскадровка (Storyboard)** — карточки сцен, которые можно перетаскивать и
  менять порядок.
- **Персонажи** — карточки персонажей и детальная страница каждого (внешность,
  роль) для консистентных промптов.
- **Локации** — справочник мест и окружений.
- **Стили** — переиспользуемая визуальная «грамматика» (prompt-шаблоны).
- **Промпты** — конструктор промптов из блоков (character, action, environment,
  lighting, camera, style, negative) с версионированием и копированием.
- **Ассеты** — учёт версий сгенерированных материалов и их одобрение.
- **Озвучка и музыка** — черновики нарации и музыкальных тем.
- **Экспорт** — страница подготовки манифеста к финальному рендеру.
- **Глобальный поиск** — по `⌘K` / `Ctrl+K`.
- Хранение данных **локально в браузере** (не нужны аккаунты и ключи), с
  готовым переходом на Supabase.

## Стек

- **Next.js 15** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS** (тёмная тема, собственные дизайн-токены)
- **lucide-react** — иконки
- Хранение: **localStorage** по умолчанию; опционально **Supabase** (Postgres)
- AI-генерации: внутренний реестр провайдеров (`services/ai/*`), в фазе 1 —
  no-op заглушки

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
```

Другие скрипты:

```bash
npm run build    # прод-сборка
npm start        # запуск собранного приложения
npm run lint     # проверка линтером Next.js
```

При открытии приложение переходит на `/dashboard` и наполняет локальную базу
демо-проектом **The Eagle Journey** (20 сцен, показывается 85% готовности).
Никаких учётных данных для запуска не нужно.

### Переключение на Supabase (опционально)

1. Создайте `.env.local`:

   ```bash
   NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
   ```

2. Примените миграцию `supabase/migrations/schema.sql` (в SQL-редакторе
   Supabase или через `supabase db push`).
3. Перезапустите `npm run dev`.

Когда эти переменные заданы, приложение автоматически начинает использовать
Supabase. Код UI при этом не меняется.

## Структура проекта

```
src/
  app/                     страницы (App Router): dashboard, projects,
                           project/[id]/{script,storyboard,characters,
                           locations,styles,prompts,assets,voiceover,
                           music,export}, settings
  components/
    ui/                    базовые UI-компоненты (button, card, drawer, …)
    studio/StudioViews.tsx основные экраны Studio
    layout/AppShell.tsx    каркас приложения (навигация)
    media/                 плееры, загрузчик файлов, превью изображений
  lib/
    types.ts               типы домена (Project, Scene, Character, …)
    local-db.ts            локальная база + демо-данные (The Eagle Journey)
    db/                    репозиторий: index.ts выбирает local или supabase
services/ai/              реестр AI-провайдеров и композиция промптов (stubs)
supabase/                 схема БД для Supabase
```

Вся работа с данными идёт через единый интерфейс
`src/lib/db/repository.ts` — реализации local и Supabase взаимозаменяемы.
